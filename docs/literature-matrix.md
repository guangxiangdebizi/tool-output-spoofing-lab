## Consolidation rules

- Prefer original papers, official project pages, and benchmark repositories.
- Do not count surveys as novelty-blocking unless they point to the original
  work that fully overlaps this idea.
- For each paper, record the exact claim it blocks.
- Mark "direct overlap" only if the paper studies fabricated/tampered tool
  observations, not merely prompt injection in retrieved text.
- Keep "tool hallucination" separate from "tool-output spoofing": in
  hallucination the model invents/misuses a tool; in spoofing a called tool
  returns an untrustworthy observation.
- Track whether a paper has a truth oracle or paired truthful-vs-spoofed
  comparison. This is likely the lab's most important differentiation.
