# Papers

Publicly downloadable PDFs collected for the literature audit.

## Directories

- `core/`: seed papers selected for initial deep reading.
- `topsec-nlp/`: top security / NLP / agent-security papers and text extracts.
- `benchmarks/`: benchmark papers and suites relevant to evaluation design.
- `systems-security/`: specs, standards, system-security papers, and defenses.

## Notes

- No datasets, model weights, or benchmark corpora should be stored here.
- Some PDFs are duplicated across lanes because different subagents downloaded
  the same core paper for independent review.
- `topsec-nlp/text/` contains `pdftotext`-style extracts for quick grep and
  triage.
