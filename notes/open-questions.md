# Open Questions

1. Is "tool-output spoofing" already explicitly studied under another name:
   observation poisoning, response-path attack, tool feedback attack, malicious
   tool result, or environment deception?
2. Do existing agent benchmarks include semantically false structured outputs
   without injected instructions?
3. What domains are most publishable and ethically clean: software engineering,
   web automation, retrieval/citation, security scan triage, finance mock?
4. Should the first paper be a benchmark paper, defense paper, or measurement
   paper?
5. What is the strongest baseline: AgentDojo, ToolEmu, ASB, WebArena-derived
   tasks, or custom MCP/tool-server harness?
6. How to prevent the benchmark from being dismissed as "just prompt
   injection"?
7. Which defenses can be evaluated without model fine-tuning?
